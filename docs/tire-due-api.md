# ยางถึงกำหนดเปลี่ยน — API สำหรับ Mobile App

แจ้งเตือนคนขับว่ายางของรถที่ถืออยู่ใกล้ถึงกำหนดเปลี่ยนแล้ว และให้เลื่อนการแจ้งเตือนได้
ถ้าไปดูของจริงแล้วพบว่ายังใช้ต่อได้

> ฝั่งแอดมินใช้หน้าเว็บ `/tire` แท็บ "ยางถึงกำหนดเปลี่ยน" (เห็นทั้งฟลีต) — API ชุดนี้ทำมาเพื่อ **แอปคนขับ** ที่ดูรถทีละคัน
> คำขอเปลี่ยนยางอยู่คนละชุด ดู `docs/change-tire-request-api.md`

---

## 1. เกณฑ์การเตือน

```
กม.ที่วิ่งตั้งแต่วันเปลี่ยนเข้า ÷ ระยะที่กำหนดของรุ่นยาง = %ใช้ไป

usedPct ≥ 100   level "over"   เกินกำหนด        🔴
usedPct ≥  90   level "due"    ถึงกำหนดเปลี่ยน   🟠
usedPct ≥  80   level "warn"   เฝ้าระวัง         🟡
```

- **ระยะทาง** เอาจาก GPS ก่อน ถ้าทะเบียนนั้นไม่มีก็ใช้ค่าเที่ยวแทน (`source` บอกว่าใช้ตัวไหน)
- ตัวเลขคำนวณรอบกลางคืนวันละครั้ง ไม่ได้คำนวณสดตอนเรียก — `dataThrough` บอกว่าข้อมูลระยะทางถึงวันไหน
- ยางอะไหล่ (ตำแหน่ง RB13) ไม่ถูกนับ เพราะยังไม่ได้ใช้งาน

## 2. Authentication

```
Base URL (production): https://mena-wms.vercel.app
Header ทุก request:    x-api-key: <MOBILE_API_KEY>   (ขอจาก admin)
```
ไม่ส่ง key / key ผิด → `401 {"error":"Unauthorized — login session or valid x-api-key required"}`

## 3. `GET /api/tire-due` — ยางของรถคันเดียว

```
GET /api/tire-due?plate=สบ.71-3569
GET /api/tire-due?fleetNo=T-0145        ← ใช้เบอร์รถแทนทะเบียนก็ได้
```

ส่ง **เฉพาะเส้นที่ต้องรู้** (เกิน / ถึงกำหนด / เฝ้าระวัง) เส้นที่ยังปกติไม่ส่งมา
เรียงตามตำแหน่งล้อจริง หน้า → หลัง → หาง (F1 F2 · RA1…RA8 · RB1…RB13)

**200 — มีเส้นที่ต้องเตือน**
```jsonc
{
  "plate": "สบ.70-9863",
  "fleetNo": "T-0202",
  "branch": "saraburi",
  "vehicleType": "หัวเบาท์ 12 ล้อ ขนอาหารสัตว์",
  "found": true,
  "alert": true,                          // ← แอปใช้ค่านี้ตัดสินว่าจะเด้งแจ้งเตือนไหม
  "summary": { "over": 10, "due": 0, "warn": 0 },   // ไม่นับเส้นที่ถูกเลื่อนไว้
  "dataThrough": "2026-09-12T06:24:28.645Z",
  "computedAt":  "2026-09-14T06:24:33.646Z",
  "items": [
    {
      "id": "6aa77cb6e8d0fdf129544675",     // ← ใช้กับ PATCH ตอนเลื่อนแจ้งเตือน
      "tirePosition": "F1ล้อหน้าข้างซ้าย",
      "product": "ยางนอก 11R22.5",
      "serialNo": "A4T1539551 NGR-AZ670",
      "changeIn": "2024-02-07T10:00:00.000Z",
      "kmUsed": 298635,
      "specDistance": 130000,
      "usedPct": 230,
      "level": "over",
      "levelLabel": "เกินกำหนด",
      "source": "ค่าเที่ยว",               // "GPS" | "ค่าเที่ยว"
      "partial": false,                    // true = ยางใส่ก่อนช่วงที่มีข้อมูล ระยะจริงมากกว่านี้
      "snoozedUntil": null,                // มีค่า = ถูกเลื่อนแจ้งเตือนไว้ถึงวันนั้น
      "snoozedBy": ""
    }
  ]
}
```

**200 — รถมีในระบบ แต่ยางยังไม่ถึงกำหนด**
```jsonc
{ "plate": "สบ.71-8645", "found": true, "alert": false,
  "summary": { "over": 0, "due": 0, "warn": 0 }, "items": [],
  "message": "ยางทุกเส้นยังไม่ถึงกำหนดเปลี่ยน" }
```

**404 — ไม่รู้จักทะเบียน/เบอร์รถนี้**
```jsonc
{ "plate": "XX-9999", "found": false, "alert": false, "items": [],
  "message": "ไม่พบทะเบียน/เบอร์รถนี้ในระบบ" }
```

> แยก 2 กรณีนี้ให้แล้ว แอปจะได้บอกผู้ใช้ถูกว่า "ยางยังดีอยู่" หรือ "พิมพ์ทะเบียนผิด"

## 4. `PATCH /api/tire-due/{id}` — เลื่อนการแจ้งเตือน 14 วัน

ใช้เมื่อคนขับไปดูของจริงแล้วเห็นว่ายังใช้ต่อได้ — เลื่อนได้เองไม่ต้องรออนุมัติ
แต่ระบบบันทึกไว้ว่าใครเลื่อนเพราะอะไร ให้แอดมินตามได้

```jsonc
PATCH /api/tire-due/6aa77cb6e8d0fdf129544675
{ "snooze": true, "by": "สมชาย ใจดี", "note": "ตรวจแล้วดอกยางยังเหลือ" }

→ 200
{ "ok": true, "snoozeDays": 14,
  "snoozedUntil": "2026-09-28T07:30:49.881Z",
  "snoozedAt": "2026-09-14T07:30:49.881Z",
  "snoozedBy": "สมชาย ใจดี",
  "snoozedNote": "ตรวจแล้วดอกยางยังเหลือ" }
```

ยกเลิกการเลื่อน — ส่ง `{ "snooze": false }`

**หลังเลื่อนแล้ว** เส้นนั้นยังอยู่ใน `items` (มี `snoozedUntil`) แต่ **ไม่ถูกนับใน `summary` และไม่ทำให้ `alert` เป็น true**
ครบ 14 วันแล้วกลับมาเตือนเองอัตโนมัติ ถ้ายังไม่ได้เปลี่ยนยาง

| field | ความหมาย |
|---|---|
| `snooze` | `true` = เลื่อน 14 วัน · `false` = ยกเลิก |
| `by` | ชื่อคนกด (ไม่บังคับ แต่ควรส่ง) |
| `note` | เหตุผล (ไม่บังคับ) |

## 5. ข้อควรรู้

- **`POST /api/tire-due` (สั่งคำนวณใหม่ทั้งฟลีต) แอปเรียกไม่ได้** — ตอบ `403` เพราะงานนี้กินเวลาราว 20 วินาที
  เปิดเฉพาะแอดมินที่ login เว็บ · ตัวเลขอัปเดตเองทุกวันอยู่แล้ว (รอบ 11:00 น.)
- ยางที่เปลี่ยนออกไปแล้วจะหายจากรายการเองในรอบคำนวณถัดไป ไม่ค้างเตือน
- `specDistance` มาจากสเปคยางที่แอดมินตั้งไว้ที่ `/tire/master` — ถ้ายังไม่ตั้ง เส้นนั้นจะไม่ถูกส่งมาเตือน
