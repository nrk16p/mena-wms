# อะไหล่ Hub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** เพิ่มอะไหล่ Hub (consignment ของ Sub) ใน mena-wms: master + ยอดคงเหลือ + รับเข้า, กล่อง Hub ในฟอร์มเบิก, ตัดยอด Hub + WD Hub แยกใบ (ตัดจากคลัง Hub ใน ATMS), ผูก PR ภายใน 1 วัน + เตือน, Sub ดูยอดใน vendor-portal

**Architecture:** บรรทัด Hub อยู่ในใบ SW เดิม (`SwLine.hub`) · ตัดยอด Hub ใน Mongo (`hub_stock` + สมุด `hub_moves`) · WD Hub ยิง `/atms/withdraw/issue` ครั้งแยก (`remark_token ${no}-H`, `inventory_id` = คลัง Hub) เก็บ progress ใน `hubWd` และไม่ทำให้สถานะหลักของใบค้าง · Mobile/PM: ตัดยอดตอน handOut, WD Hub ต่อทะเบียนตอน settle

**Tech Stack:** Next.js (App Router) + TypeScript, MongoDB driver, tsx check scripts + mongodb-memory-server, Tailwind

**Spec:** `docs/superpowers/specs/2026-11-20-hub-parts-design.md`

## Global Constraints

- ห้ามเขียนลง ATMS / prod DB · ห้าม `git fetch`/push · ทดสอบด้วย mongodb-memory-server + stub fetch เท่านั้น (`delete process.env.MONGO_URI` ทุก check)
- route ใหม่ทั้งหมดอยู่ใต้ `/api/store-withdraw/*` หรือ `/api/vendor-portal/*` เท่านั้น (ห้าม `/api/hub/*` — จะถูก rewrite ไป mena-backend-services)
- collection ใหม่อยู่ใน db เดียวกับ store-withdraw (`getDb()` ใน `lib/store-withdraw/db.ts`)
- รหัส Hub = SKU ATMS (`skuId` = skuPk ของ `atms_sku_master`)
- ยอด Hub ห้ามติดลบ · ตัดซ้ำห้ามเกิด (unique `hub_moves`) · WD Hub ล้มห้ามทำให้ส่วนปกติค้าง และกลับกัน
- นับเกินกำหนด PR = 24 ชม. จาก `hubIssuedAt` · เตือนในระบบอย่างเดียว ไม่บล็อก ไม่ LINE
- กล่อง Hub ใช้ได้กับงาน อู่ใน (`garage_in`) และ Mobile/PM (`mobile_pm`) · ซ่อนกับ อู่นอก (`garage_out` = ซื้อมาใช้เลย ไม่ได้มาจากสโตร์) — การตัดสินของผู้เขียน plan
- Sub เห็นเฉพาะ `hub_stock` ของ `vendorCode` ตัวเอง: รหัส ชื่อ คงเหลือ หน่วย (ไม่มีราคา/ประวัติ/ผู้เบิก)
- ข้อความบนจอ: ภาษาคนพูด สั้น (ตาม humanizer) · ใช้ `swalError`/`swalToast` เดิม ไม่ใช้ window.alert
- คงสไตล์ไฟล์เดิม: คอมเมนต์ไทยสั้น, สี `#1B8C4B`, ฟังก์ชันล้วนอยู่ไฟล์ที่ไม่แตะ DB

  - `hubCols(): Promise<{ sites; vendors; items; stock; moves }>` — สร้าง index ครั้งแรก: items/stock unique `{inventoryId,vendorCode,skuId}` · moves unique `{type,refNo,lineIndex}` partial เฉพาะ type in ["issue","return"] · moves `{vendorCode,at}`, `{refNo}`
  - `getHubSite(inventoryId: number): Promise<HubSite | null>` (เฉพาะ active)
  - `receiveHub(input: { inventoryId; vendorCode; refNo; lines: { skuId; skuCode; skuName; unit?; price?; qty }[] }, by): Promise<HubMove[]>` — upsert `hub_items` (ไม่ทับราคาเดิมถ้าไม่ส่งมา), `$inc` stock, insert move "receive" · vendor ต้อง active
  - `cutHubForRequest(no: string, plan: ReturnType<typeof hubCutPlan>, inventoryId: number, by): Promise<{ ok: true } | { ok: false; short: { skuCode?: string; skuId: number; have: number; need: number }[] }>`
  - `restoreHubForRequest(no: string, by, note: string): Promise<number>` — คืนทุก move "issue" ของ `refNo = no` ที่ยังไม่ถูกคืน: insert move "adjust" (+qty, `note`) + `$inc` stock · คืนจำนวนบรรทัดที่คืน · เรียกซ้ำ = 0 (ใช้ `adjust` refNo `${no}:restore` lineIndex เดิม เช็กก่อนแทรก)
  - `returnHubLeftover(no: string, items: { lineIndex; vendorCode; skuId; qty }[], inventoryId, by): Promise<void>` — move "return" unique ต่อบรรทัด + `$inc`
  - `searchHubItems(inventoryId: number, q: string, limit: number): Promise<(HubItem & { qty: number; vendorName: string })[]>`
  - `listHubStock(filter: { inventoryId?: number; vendorCode?: string }): Promise<(HubItem & { qty: number })[]>`
  - `listHubMoves(filter: { vendorCode?: string; skuId?: number; from?: Date; to?: Date }, limit: number): Promise<HubMove[]>`

Algorithm ของ `cutHubForRequest` (ไม่มี transaction — memory server single node):
```
done = []
for p of plan:
  if moves มี {type:"issue", refNo:no, lineIndex:p.lineIndex} แล้ว → ข้าม (idempotent)
  r = stock.updateOne({inventoryId, vendorCode:p.vendorCode, skuId:p.skuId, qty:{$gte:p.qty}}, {$inc:{qty:-p.qty}})
  if r.modifiedCount === 0 → ถอยทุกตัวใน done ($inc +qty) แล้วคืน {ok:false, short:[...ทุกบรรทัดที่ไม่พอ คำนวณจาก stock ปัจจุบัน]}
  try insert move issue (-qty) catch duplicate → $inc +qty กลับ (อีก request ตัดไปแล้ว) แล้วข้าม
  done.push(p)
return {ok:true}
```
