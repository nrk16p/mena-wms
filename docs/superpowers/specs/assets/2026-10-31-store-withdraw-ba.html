เบิกอะไหล่ออนไลน์ และจอคิวงานสโตร์

ยานยนต์ยื่นใบเบิกในเว็บแทนกระดาษ ใบเบิกไปเข้าคิวที่จอสโตร์เหมือนออเดอร์ในครัว พอสโตร์กดส่งของ ระบบจะสร้างใบเบิก (WD) ใน ATMS ให้เองด้วยบัญชีของสโตร์คนนั้น สโตร์ไม่ต้องไปคีย์ซ้ำอีกรอบ ส่วนของที่คืนก็ทำผ่านทางเดียวกัน

ATMS ทำงานยังไง (สำรวจแล้ว 31/10/2026)

ใบเบิก 1 ใบต้องยิง 3 จังหวะ คือสร้างหัวใบ เพิ่มรายการทีละบรรทัด แล้วกดอนุมัติ สต๊อกถูกตัดตอนอนุมัติ ฟอร์มของ ATMS ไม่มีตัวกันยิงซ้ำ เราเลยส่งตรงได้ วิธีเดียวกับที่ api-ncac ใช้เปิดใบแจ้งซ่อมอยู่ตอนนี้

จังหวะหน้า ATMSช่องที่ต้องส่ง
1. หัวใบ WD/inv/withdraw/addคลัง · จุดประสงค์ในการเบิก (60 แบบ CM-/AC-/OTH-) · ค่าใช้จ่ายเสริม · หมายเหตุ (ใส่เลขคำขอ WMS ไว้ตามหาใบ)
2. รายการ/inv/withdraw.item/add/…รายการแจ้งซ่อม (MR item) · SKU · serial ถ้าเป็นของมีเลขเฉพาะ · จำนวน · หมายเหตุ
3. อนุมัติ/inv/withdraw/approve/id/…ยังไม่ได้ลองกดจริง ต้องทดสอบก่อน
คืนของ/inv/deposit/addใบรับไม่ใส่ PO แต่อ้างเลข WD เดิม ส่วนหน้าเพิ่มรายการคืนยังไม่ได้เปิดดู
ค้นข้อมูลjson ของ ATMSค้น MR item (ได้ชื่อช่างและคนขับมาด้วย) · ค้น SKU ตามคลัง · ค้น serial · ค้นเลข WD
ผู้ใช้/account/user/profileusername · อีเมล · สาขา · แผนก · เป็นช่างไหม เอาไว้ผูกบัญชีและเลือกคลังเริ่มต้นให้สโตร์

ช่องค้น SKU ของ ATMS ไม่ส่งยอดคงเหลือกลับมา ตอนยื่นคำขอจะโชว์ยอดจากสำเนาที่ WMS ซิงก์ไว้ทุกคืน พอถึงตอนสโตร์จัดของค่อยอ่านยอดสดจาก ATMS อีกที

กันไม่ให้ตัดสต๊อกซ้ำ

เรื่องที่ห้ามเกิดที่สุดคือมี WD สองใบจากคำขอเดียว ซึ่งเกิดได้ถ้ากดส่งซ้ำ เปิดสองแท็บ หรือเน็ตหลุดกลางทาง

ตอนกดส่ง ระบบจะล็อกคำขอไว้ก่อน ใครกดซ้ำก็ไม่ยิงซ้ำ สร้างหัวใบเสร็จจะจด id ไว้ทันที แต่ละบรรทัดก็ติ๊กไว้ทีละบรรทัด ถ้าพังกลางทาง ปุ่มลองใหม่จะเริ่มจากขั้นที่ค้าง ไม่สร้างหัวใบใหม่ ถ้าไม่แน่ใจว่าหัวใบสร้างไปแล้วหรือยัง ระบบจะค้น WD ที่มีเลขคำขออยู่ในหมายเหตุก่อน

ยิง ATMS ห่างกันประมาณ 1 วินาที และให้สโตร์หนึ่งคนส่งได้ทีละใบ เพราะเคยยิงติดกัน 176 ครั้งแล้ว ATMS error ไป 40%

ตามให้ตรงกับ ATMS

ใน ATMS แก้ WD ย้อนหลังได้ ถ้ามีคนไปถอนอนุมัติ ลบ หรือแก้จำนวนในใบที่ WMS สร้าง ระบบจะขึ้นธง "ATMS ถูกแก้" ให้สโตร์เห็น จะไม่แก้ข้อมูลฝั่ง WMS เอง ใบอายุ 7 วันล่าสุดจะถูกเช็กซ้ำเป็นรอบ ๆ จาก api-ncac และเช็กทุกครั้งที่มีคนเปิดดูใบ

รอบเช็กไม่ใช้ cron ของ Vercel เพราะ WMS ใช้ครบ 2 ตัวตามเพดานของแพ็กเกจแล้ว

แผนงาน

  1. สำรวจ ATMS ส่วนที่เหลือ เปิดหน้าเพิ่มรายการคืน ดูวิธีติ๊ก "คืนอะไหล่ครบแล้ว" แล้วลองกดอนุมัติกับใบทดสอบ LBWD26102206 ดูว่าตัดสต๊อกตอนไหน ขั้นนี้ต้องให้คุณอนุญาตก่อน เพราะมีการเขียนข้อมูลลง ATMS จริง และต้องตอบคำถามที่ค้างให้จบในขั้นนี้
  2. api-ncac: ตัวยิง ATMS ทำ route สร้างหัวใบ เพิ่มรายการ อนุมัติ และเปิด view ตรวจผล ของคืนก็ทำชุดเดียวกัน รวมถึง login + อ่าน profile และช่องค้น MR/SKU/serial ทุก route มีโหมดลองยิง (dry-run) ที่ไม่บันทึกจริง
  3. WMS: ข้อมูลและ API ทำคอลเลกชันคำขอ เลขใบ SW-YYMM-NNN สถานะตามตาราง log ทุกครั้งที่สถานะเปลี่ยน สิทธิ์ผู้ขอกับสโตร์ใช้ระบบสิทธิ์ตามแผนกที่มีอยู่ เปิด API key และทำ test ของ state machine
  4. หน้าผู้ขอเบิก ฟอร์มยื่นคำขอที่เห็นสต๊อก รายการคำขอของฉันที่อัปเดตเอง และปุ่มรับแล้ว ต้องใช้บนมือถือได้
  5. จอคิวสโตร์ + ผูกบัญชี ATMS ทำจอแบบครัว รับงาน จัด ส่ง ลองใหม่ เสียงเตือน แล้วทดสอบส่งจริงกับ WD 1 ใบที่ลาดกระบังโดยมีสโตร์ดูอยู่ด้วย
  6. คืนของ ทำการขอคืน การรับคืน การสร้าง DD อ้าง WD และติ๊กคืนครบ
  7. ซิงก์กลับ รอบเช็กใบ 7 วัน ธง "ATMS ถูกแก้" และหน้าคู่มือ API
  8. นำร่องลาดกระบัง ใช้คู่กับกระดาษ 2 สัปดาห์ เทียบเลข WD ทุกใบกับ ATMS ทำคลิปสอนสั้น ๆ แล้วค่อยขยายไปคลังอื่น

ข้อ 2 กับ 3 ทำคู่กันได้ หน้าจอข้อ 4 และ 5 รอ API ข้อ 3 ก่อน โค้ดแยก branch ใหม่ทั้ง WMS และ api-ncac และจะไม่ push ขึ้น production จนกว่าคุณจะสั่ง

ความเสี่ยงที่รู้อยู่

  • session ATMS อยู่ได้ประมาณ 30 นาที ถ้าไม่เก็บรหัสผ่านไว้ สโตร์อาจต้อง login ATMS ใหม่หลายรอบต่อวัน
  • ATMS ทั้งระบบรับโหลดได้น้อย ถ้ามีหลายคลังกดส่งพร้อมกันต้องต่อคิวฝั่ง api-ncac
  • api-ncac บน Render ถ้าหลับอยู่ ครั้งแรกที่ปลุกจะช้า การกดส่งครั้งแรกของวันอาจรอหลายวินาที
  • ยอดสต๊อกตอนยื่นคำขอมาจากสำเนาที่ซิงก์ทุกคืน ยอดที่เห็นอาจไม่ตรงกับของจริงในวันนั้น
  • ถ้ามีคนแก้ WD ใน ATMS เอง WMS ทำได้แค่ขึ้นธงเตือน ยังแก้ข้อมูลกลับให้เองไม่ได้

คำถามที่ยังค้าง ยังต้องถาม

  1. ใบเบิกตัดยอด ใครเป็นคนเริ่ม ยานยนต์ยื่นเอง หรือสโตร์เปิดเองตอนรับ DD เข้าระบบ
  2. "Safety Stock" กับ "อะไหล่ลงคัน" ในโน้ตคืออะไร เป็นจุดประสงค์การเบิก หรือเป็นประเภทคำขออีกแบบ
  3. จะเก็บรหัสผ่าน ATMS ของสโตร์แบบเข้ารหัส ให้ระบบ login ใหม่เองไหม หรือให้สโตร์กรอกใหม่ทุกครั้งที่หมด
  4. ต้องให้หัวหน้าอนุมัติคำขอก่อนเข้าคิวสโตร์ไหม
  5. นำร่องที่คลังลาดกระบังก่อนใช่ไหม
  6. ใบที่คนคีย์ตรงใน ATMS ต้องขึ้นในจอคิวด้วยไหม
