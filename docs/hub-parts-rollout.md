# อะไหล่ Hub: ขั้นตอนก่อนทดสอบจริง

ทำตามลำดับนี้ก่อนเปิดให้สโตร์ใช้ ข้ามข้อไหนไม่ได้ ข้อ 2 ต้องรอเลขคลังจาก ATMS ก่อน

## ขั้นตอน

1. ให้สิทธิ์ store-hub รายคน
   - เข้า /admin/users แล้วติ๊กสิทธิ์ store-hub ให้คนที่จะดูแล Hub (สโตร์ และคนที่ต้องรับของเข้า)
   - คนที่ได้สิทธิ์แบบดูอย่างเดียวจะเห็นหน้า /store-withdraw/hub แต่ไม่มีแท็บรับเข้า และกดบันทึกไม่ได้

2. ตั้งคลัง Hub
   - ต้องขอ/สร้างเลขคลัง Hub ใน ATMS ก่อน ถ้ายังไม่มีเลข ข้อ 6 จะตัด WD Hub ไม่ได้
   - เข้า /store-withdraw/hub แท็บ Sub แล้วใส่เลขคลัง Hub ของ ATMS ให้คลังลาดกระบัง (คลัง 4) กดบันทึก
   - ติ๊ก เปิดใช้ แล้วกดบันทึกที่แถวคลัง 4
   - คลังไหนไม่ตั้ง จะไม่เห็นกล่อง Hub ในฟอร์มเบิก

3. เพิ่ม Sub
   - แท็บ Sub กดเพิ่ม ใส่รหัสผู้ขายให้ตรงกับใน ATMS ทุกตัวอักษร
   - รหัสนี้ใช้ตัดสต๊อกและใช้ล็อกอิน vendor-portal ด้วย พิมพ์ผิดแล้ว Sub จะไม่เห็นของตัวเอง

4. สร้างบัญชี vendor-portal
   - เข้า /ap-tracking/suppliers สร้างบัญชีให้ Sub ตามรหัสผู้ขายเดียวกับข้อ 3
   - ล็อกอินด้วยบัญชีนั้นแล้วต้องเห็นแท็บ "สต๊อกฝากขาย" ถ้าไม่เห็นแปลว่ารหัสไม่ตรง

5. รับของเข้าครั้งแรก
   - แท็บรับเข้า เลือก Sub ใส่เลขที่เอกสาร ค้นหา SKU ใส่จำนวนกับราคา แล้วกดยืนยัน
   - เลขที่เอกสารซ้ำจะถูกปฏิเสธ (409) เพื่อกันรับซ้ำ
   - เช็กว่ายอดในแท็บยอดคงเหลือขึ้นตรง และ Sub เห็นจำนวนเท่ากัน
   - การรับเข้านี้ลงในระบบ WMS เท่านั้น ต้องรับเข้า ATMS แยกอีกทาง

6. ทดสอบเบิก 1 ใบต่อประเภท
   - คนทดสอบฝั่งสโตร์ต้องผูกบัญชี ATMS ของตัวเองก่อน เหมือนเบิกปกติ
   - ใบที่ 1: งานอู่ใน (garage_in) เลือกของจากกล่อง 4 (Hub) ส่งใบ แล้วให้สโตร์จ่าย
   - ใบที่ 2: งาน Mobile/PM เบิกของ Hub แล้วทำให้ถึงขั้นสรุป
   - ลองกรณีไม่มี PR: ส่งใบโดยไม่เลือก PR ต้องส่งได้ และใบขึ้น "รอ PR อะไหล่ Hub"
   - ลองผูก PR ทีหลัง: เปิดใบ กด "ผูก PR อะไหล่ Hub" เลือก PR ป้ายขึ้นว่าผูกแล้ว
   - ลองตัด WD Hub ใหม่: ถ้า WD Hub ล้ม ต้องมีปุ่ม "ลองตัด WD Hub ใหม่" กดแล้วได้เลข WD
   - เช็กยอด Hub ลดตามจำนวนที่จ่าย และใบส่วนอะไหล่ปกติไม่ค้างเพราะ Hub

## ข้อจำกัด phase 1

1. ยังคืนของให้ Sub ไม่ได้
2. ยังไม่มีนับสต๊อก Hub
3. ยังไม่แจ้งเตือนทาง LINE เตือน PR เกิน 24 ชม. ขึ้นในหน้าแอปอย่างเดียว และไม่บล็อกงาน
4. การรับของเข้า ATMS ทำแยกต่างหาก ระบบนี้ไม่ลงให้
5. อู่ใน: ปฏิเสธ/ปิดใบหลังจ่ายแล้ว ระบบคืนยอด Hub ให้ ยกเว้นกรณี WD Hub อาจเกิดใน ATMS แล้ว ระบบจะไม่คืน และหน้า audit ของใบขึ้นว่า "ข้ามการคืนยอด Hub (ต้องเช็กเอง)" (log hubRestore-skipped) ต้องเช็ก WD ใน ATMS เอง
6. Mobile/PM: จ่ายของแล้วยกเลิกไม่ได้ ของเหลือคืนเข้ายอด Hub ตอนสโตร์ยืนยันรับคืนในขั้นสรุป
7. ยอด Hub ไม่พอตอนจ่าย ระบบไม่ตัดสักบรรทัด ใบกลับไปสถานะ PREPARING ให้แก้จำนวน ถ้าระบบติดงานอื่นอยู่ (busy) ใบจะอยู่ READY เหมือนเดิม ให้กดใหม่

## เช็กลิสต์คลิกทดสอบ

ฟอร์มเบิก
1. คลังที่เปิด Hub + งานอู่ใน: เห็นกล่อง 4
2. คลังที่ไม่เปิด Hub: ไม่เห็นกล่อง ฟอร์มเหมือนเดิม
3. พิมพ์ค้นหา 2 ตัวขึ้นไปในกล่อง 4 แล้วเลือก: บรรทัดมีป้าย Hub กับ "คงเหลือ Hub n" SKU เดียวกับกล่อง 3 แยกคนละบรรทัด เลือกของ Hub ซ้ำให้บวกจำนวน
4. ใส่จำนวนเกินยอด Hub: ขึ้นเตือนสีเหลือง แถบสรุปมี "· Hub m"
5. ตัวเลือก PR ของ Hub: ไม่มีสวิตช์ PR/PO/DD ไม่มี "ดูรายการ" เลือกแล้วขึ้นชิป ล้างได้ ส่วน "อ้างอิงใบ PR / PO / DD" เดิมยังครบ
6. สลับเป็นอู่นอกทั้งที่มีบรรทัด Hub: บรรทัด Hub หายพร้อมแจ้ง เปลี่ยนคลัง บรรทัด Hub หาย
7. งาน Mobile/PM: เห็นกล่อง 4 ใบหลายประเภทต้องเลือกประเภทให้บรรทัด Hub ก่อนส่ง
8. ส่งใบที่มีบรรทัด Hub: ส่งได้ ใบที่ไม่มี Hub ต้องไม่มีข้อมูล Hub ติดไป

คิวสโตร์และ "ใบของฉัน"
9. ใบ Hub จ่ายเกิน 25 ชม. ไม่มี PR: การ์ดขึ้น "Hub 1" กับ "เกินกำหนด PR"
10. แบนเนอร์ขึ้น "รอผูก PR อะไหล่ Hub 1 ใบ · เกินกำหนด 1 ใบ"
11. กดชิปหรือปุ่มในแบนเนอร์: เหลือเฉพาะใบรอ PR
12. ช่องเสร็จวันนี้: จ่ายวันนี้ขึ้น "ส่งแล้ววันนี้ -> รอ PR อะไหล่ Hub"
13. จ่ายเมื่อวานขึ้น "ส่งแล้ว dd/mm -> ..."
14. ใบรอ PR ที่เก่ากว่า 48 ชม. ต้องยังเห็นอยู่
15. เปิดรายละเอียด: มีส่วน "รายการอะไหล่ Hub"
16. กด "ผูก PR อะไหล่ Hub" ค้นหาทะเบียน เลือก PR กด "ผูก PR" แล้วมีแจ้งสำเร็จ
17. ป้ายกับแบนเนอร์หายในรอบโหลดถัดไป
18. WD Hub ล้ม: บรรทัดขึ้น "WD Hub: ... error" และมีปุ่ม "ลองตัด WD Hub ใหม่"
19. บัญชีที่ยังไม่ผูก ATMS ต้องเจอหน้าผูกก่อนตัดใหม่
20. กดตัดใหม่สำเร็จ: ขึ้นแจ้งสำเร็จ ถ้ายังไม่ได้ผลขึ้นให้ลองเช็กอีกครั้ง
21. ใบ Mobile/PM ที่ SETTLED แล้วกลุ่ม Hub ล้ม: มีปุ่มเดียวกัน
22. สรุป Mobile/PM: ทะเบียนที่มีทั้งของปกติและ Hub เห็น "WD ..." และ "WD Hub ..." ใต้ทะเบียนเดียวกัน
23. หน้า "ใบของฉัน": แบนเนอร์เห็นเฉพาะใบของตัวเอง
24. เจ้าของใบเห็นปุ่ม "ผูก PR อะไหล่ Hub"
25. หน้า audit: ไทม์ไลน์แสดงการกระทำของ Hub เป็นภาษาไทย
26. ใบที่ไม่มี Hub ต้องไม่มีป้าย แบนเนอร์ ส่วน หรือปุ่ม Hub ที่ไหนเลย

หน้า /store-withdraw/hub
27. คนมีสิทธิ์แก้: เห็น 5 แท็บ คลัง = ลาดกระบัง ตารางยอดโหลดและค้นหากรองได้
28. แท็บ Sub: เพิ่ม Sub ปิด/เปิดได้ ใส่เลขคลัง Hub ของ ATMS แล้วบันทึกได้
29. แท็บรับเข้า: เลือก Sub ใส่เลขที่เอกสาร เพิ่ม SKU ใส่จำนวน/ราคา ยืนยัน แล้วรายการล้างและยอดขึ้น ส่งเลขที่เอกสารเดิมซ้ำต้องขึ้น 409
30. แท็บรายการอะไหล่: แก้ราคา/หน่วยแล้วบันทึกได้ ปิดใช้แล้วแถวจางลง
31. แท็บความเคลื่อนไหว: กรองได้ แถวมี +/- กดดาวน์โหลด Excel ได้ไฟล์ hub-moves.xlsx
32. คนดูอย่างเดียว: ขึ้นแบนเนอร์ ไม่มีแท็บรับเข้า ช่องกรอกถูกล็อก ไม่มีปุ่มบันทึก

vendor-portal (Sub)
33. ล็อกอินด้วยบัญชี Sub ที่เปิด Hub: มีแถบแท็บ
34. แท็บ "สต๊อกฝากขาย" แสดงรหัส ชื่อ จำนวน หน่วย กับ "อัปเดตล่าสุด" ค้นหาด้วยรหัสหรือชื่อได้ "โหลดใหม่" ได้ และกลับแท็บบิลเดิมได้ปกติ
35. ล็อกอินด้วยผู้ขายที่ไม่ใช่ Sub: ไม่มีแถบแท็บ
36. ยังไม่ล็อกอิน: เรียก /api/vendor-portal/hub-stock ได้ 401 ข้อมูลที่ตอบกลับไม่มีราคาและไม่มี vendorCode
